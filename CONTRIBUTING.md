# Contributing
## Team Roles
| Role | Member | Responsibilies |
| ---- | ------ | -------------- |
| Data Wrangler | Alejandra | Data loading, missing value handling, type conversions, creating derived columns |
| Analyst | Raul | grouby/agg, pivot_table/ melt, correlation matrix, descriptive statistics, EDA questions |
| Visualization | Jake | Line, bar, histogram and scatter plots, styling and exporting figures |
| Documentation | Charlie | README, CONTRIBUTING, markdown narrative, repo structure |
## Git Workflow
1. Branches: Each member has a branch for their role
2. Pull Requests: When feature is ready, a pull request is opened before merging with main
3. Commits: Clear, descriptive commit messages
4. Issues: Issues to track tasks
## Notebook Organization
1. Data Loading: Data Wrangler
2. Cleaning and Transformation: Data Wrangler
3. Descriptive Statistics and EDA: Analyst
4. Visualizations and Feature Exploration: Visualization
5. Summary and Key Findings: Documentation
